## 🚀 Overview

Tech Glossary Hub is a developer-friendly web application built with **React** and **Vite**. It provides a structured collection of programming terms across multiple technologies, making it easier for beginners and experienced developers to quickly understand technical concepts.

The application is designed with a **clean dark UI**, responsive layout, reusable components, and scalable architecture.

## 📦 Installation

Clone the repository

```bash
git clone https://github.com/charanepuri/tech-glossary-hub-react.git
```

Navigate into the project

```bash
cd tech-glossary-hub-react
```

Install dependencies

```bash
npm install
```

Start the development server

```bash
npm run dev
```
